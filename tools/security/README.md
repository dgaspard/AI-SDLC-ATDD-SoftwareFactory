# Portable security mechanisms

`portable/` contains optional reusable scanner entry points and rule fixtures. Consumers supply application-specific policies and workloads. PetClinic calibration scripts, threat assumptions and policies live in [its repository](https://github.com/dgaspard/ai-sdlc-petclinic/tree/8c16963fcb9392907ebb14a62aa1537eca12bc43/tools/security/). Historical factory calibration results are evidence for their recorded revisions only. Scanner availability and result interpretation must be reported explicitly; no production certification or automatic approval is implied.
